# Generatore Piano Dietetico README.md File

### Project Description
The Generatore Piano Dietetico is a Python program designed to generate a personalized diet plan for four weeks. It takes input from three text files: breakfast, lunch, and dinner, and generates a meal plan based on the provided data. The program can save the plan in both text (.txt) and Word (.docx) formats.

### Installation
To install Python, follow these steps:

1. **Select Python Version**: Choose the Python version you want to install. For this project, Python 3 is recommended.
2. **Download Python Executable Installer**: Download the Python executable installer for Windows from the official Python website.
3. **Run Executable Installer**: Run the downloaded installer and follow the installation prompts.
4. **Add Python to PATH (Optional)**: If you want to add Python to your system's PATH environment variable, select the option during installation.

### Usage
To use the Generatore Piano Dietetico, follow these steps:

1. **Run the Program**: Run the Python program using the `pianoDietetico.bat` script.
2. **Provide Input Files**: Provide the three input files: breakfast, lunch, and dinner. These files should contain plain text.
3. **Generate Meal Plan**: The program will generate a meal plan based on the provided data and save it in both text (.txt) and Word (.docx) formats.

### Features
- **Meal Plan Generation**: The program generates a meal plan for four weeks based on the provided input files.
- **Text and Word Format**: The meal plan can be saved in both text (.txt) and Word (.docx) formats.
- **User Interface**: The program includes a simple graphical user interface (GUI) for easy interaction.
